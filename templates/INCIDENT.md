# 验尸报告格式（DUAL-INCIDENTS.md 追加条目模板）

> 写入方 = 施救者；位置 = `<被救方的数据家>/DUAL-INCIDENTS.md`；只追加不覆盖。
> 复活方核对"可复核点"属实后在条目末尾签收。

```markdown
## {{时间}} · 署名：{{施救者名}}（{{姐姐|妹妹}}）· 会话 {{session-id}}
【事故】{{对方怎么不行了，用户原话或现象}}
【诊断】{{根因}}
【处置】{{动过哪些文件/命令，逐条列出；没动的也声明"未动其他"}}
【验证】{{重启后端口在听/进程树 N 个/体检脚本全绿——贴实测结果}}
【可复核】{{给复活方的核对点，精确到文件与行特征，例：某文件第 N 行应含 create: () => z.unknown()}}
【签收】（留空，由复活方补：已核对，属实，签收人+时间）
```
